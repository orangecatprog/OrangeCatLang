# Security Policy

Thank you for helping keep Orange Cat Lang secure.

If you discover a security vulnerability, please report it responsibly. Do **not** disclose vulnerabilities publicly until they have been reviewed and addressed.

---

## Supported Versions

The following table indicates which versions currently receive security updates.

| Version | Supported |
| ------- | :-------: |
| Latest  |    ✅     |
| Older   |    ❌     |

---

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it privately.

Include as much information as possible:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Proof of concept (if applicable).
- Potential impact.
- Suggested mitigation (optional).

---

## Response Process

Once a report is received, the following process will be followed:

1. Confirm receipt of the report.
2. Investigate the issue.
3. Assess its severity and impact.
4. Develop and test a fix.
5. Release a patched version.
6. Publicly disclose the vulnerability after a fix is available.

---

## Disclosure Policy

Please do not publicly disclose vulnerabilities until a fix has been released.

Coordinated disclosure helps protect all users of the project.

---

## Security Best Practices

When contributing:

- Keep dependencies up to date.
- Never commit secrets or credentials.
- Validate external input.
- Write tests for security-sensitive code.
- Follow the project's coding standards.

---

## Contact

For security-related reports, please use GitHub Security Advisories or contact the maintainers through the project's official communication channels.
